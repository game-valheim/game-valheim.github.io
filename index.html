The game stays on your computer

The browser connects directly to the mod on this device. Live game traffic never passes through our servers. Nearby creatures are limited to the area your game has loaded.

From game to map

  1. Install BepInEx 5 and the Live Seed Map mod.
  2. Start Valheim and enter your world.
  3. Open the map, choose Connect game, and allow local-network access if your browser asks.

Mac installation guide

Built around native mod loading

This package combines the Apple Silicon loading fix in BepInEx 5 with UnityDoorstop 4.6.0 and a Valheim launch script.

Set up once. Launch through Steam.

  1. Extract the package into your Valheim folder.
  2. Set Steam’s launch option to run the included launch script.
  3. Add compatible mods to BepInEx/plugins and launch Valheim.

The guide includes the exact folder and launch option.
